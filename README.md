# Anonimizador de documentos judiciales

Aplicación gratuita para anonimizar demandas, sentencias y escritos **sin conexión a internet**, para usar la IA (ChatGPT, Claude, Gemini) sin exponer datos sensibles.

**Sitio y descarga:** https://darionav.github.io/anonimizador/

## Cómo se usa

1. Descargá [`Anonimizador.html`](Anonimizador.html) y abrilo con doble clic (Chrome o Edge). No hay que instalar nada.
2. Arrastrá un Word (.docx), un PDF o un .txt, o pegá el texto.
3. Tocá **Anonimizar** y revisá lo resaltado.
4. Descargá el Word o copiá el texto anonimizado y usalo con la IA.
5. Guardá la clave para revertir si después querés recuperar los datos reales.

## Privacidad

La aplicación tiene bloqueadas las conexiones a internet: el documento nunca sale de tu computadora. La clave para revertir contiene los datos originales: guardala aparte y no la compartas junto con el documento anonimizado.

Revisá siempre el resultado: ninguna detección automática es infalible.
